# Platform-controlled team registrations

No real GitHub repository or AWS identities have been registered. Each live team
requires `<team-id>.json` with exact `repository` and an `environments` map whose
entries contain `trusted_principal_arn` and an exact verified `oidc_subject`. CI role ARNs are
derived from the registered account/team/environment; bootstrap inputs are
generated by `python -m scripts.bootstrap_inputs`.
See [the enrollment procedure](../../docs/environments-and-delivery.md).
Only trusted platform maintainers edit this directory. Consumer JSON cannot
select backend destinations, AWS accounts, roles or trust.
